# Food Rescue Management

Surplus food rescue for Hubballi: hotels and mess halls post leftover cooked food, NGOs claim it, and volunteers deliver it within its FSSAI safe window.

| Folder | What |
|---|---|
| [`backend/`](backend/) | Node.js + Express API, Socket.IO, Prisma + PostgreSQL/PostGIS, BullMQ on Redis. See its README to run it. |
| [`frontend/`](frontend/) | Next.js web app (JavaScript, Tailwind, PWA) for donors, NGOs, volunteers and admins. See its README to run it. |
